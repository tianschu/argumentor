# 论证工坊 · ArguMentor v4.0

面向高校英语专业学习者的**英语论证写作教练**。学生用英语构建论证、**回答智能体的追问**、自主修订，系统再检查修订是否被读者看见。四个 DeepSeek 智能体分工提供反馈，每一条输出都经过**程序化诚信守门**。

> English version: [README.en.md](README.en.md)

---

## 一、一分钟了解

```
明确任务 → 构建论证 → 追问对话 → 自主修订 → 检查反思
  Frame      Map        Question     Revise      Reflect
```

与常见“AI 批改”工具不同的三点：

1. **学生必须回答追问。** 第 3 步不是读反馈，而是与苏格拉底式追问角色多轮对话；结论由学生自己说出，系统只负责提问。
2. **AI 不写学生的句子。** 程序层面拦截改写句、虚构文献、数据与链接；所有“你的原话”引用都逐词核对，核对不上就不显示。
3. **闭环。** 修订稿会被重新检查：每条修订重点标为“已体现／部分体现／尚未体现／学生决定不采纳”，下一轮反馈知道学生上一轮拒绝过什么。

## 二、运行

需要 **Node.js 20.3+**，无第三方依赖，无需 `npm install`。

| 系统 | 操作 |
|---|---|
| macOS | 双击 `启动论证工坊.command` |
| Windows | 双击 `启动论证工坊.bat` |
| 任意 | `npm run setup` 然后 `npm start` |

浏览器打开 `http://localhost:4186`。

```bash
npm run check          # 免费自检：验证密钥与模型（GET /models，不消耗 token）
npm run start:offline  # 离线模板模式：不调用 DeepSeek，界面明确标注“非 AI 反馈”
```

### 密钥存放在项目文件夹之外

| 系统 | 位置 |
|---|---|
| macOS / Linux | `~/.config/argumentor/env` |
| Windows | `%APPDATA%\ArguMentor\env` |

因此复制、压缩或分享项目文件夹**不会泄露密钥**。若检测到旧版遗留的项目内 `.env`，启动时会提示，`npm run setup` 可一键迁移。

## 三、五步学习流程

**1 明确任务** — 议题、目标读者、核心主张、**主张限定**（条件与范围）。教师任务可锁定议题与读者。

**2 构建论证** — 每个理由独立配有证据、**证据类型**（已收集／教师材料／个人经历／计划中／假设）、来源、**双层推理联系**（证据→理由、理由→主张）。异议可针对主张或某条理由，并需选择回应策略（反驳／让步／权衡／限定）。引用教师材料时加引号，系统会**逐词核对**引文是否真的出自该材料。

**3 追问对话** — 运行前学生先**自评**最薄弱之处；分析角色会先回应这个判断。随后：

```
论证分析 ──→ 苏格拉底式追问 ┐
   (A)      ╲                ├─→ 修订协调 (R) ──→ 诚信守门
             ╲→ 语言教练 (L) ┘
```

学生对每个追问最多回答 3 轮，教练可 probe / press / acknowledge / close，但**绝不代答**。看不懂某条反馈时，可点“这条什么意思？”单独追问。

**4 自主修订** — 左栏是反馈与“你在对话中的发现”，右栏是编辑器。每条修订重点必须作出决定：**采纳／调整／不采纳／还没看懂**，拒绝也要写理由。可显示初稿与修订稿的词级差异。

**5 检查反思** — 修订检查只描述“读者现在能看到什么”，**不打分**。然后写下可迁移的策略（下个任务开始时会提醒）、确认 AI 使用说明、导出记录。

## 四、诚信守门（程序，不是提示词承诺）

每条模型输出在显示给学生之前都要通过 `guard.mjs`：

| 检查 | 处理 |
|---|---|
| 引用“你的原话” | 逐词在学生文本中定位；找不到则隐藏该引用并记录 |
| 文献、URL、DOI、年份、百分比、统计数字 | 不在学生文本中出现即判为虚构 → 修复调用 |
| 改写句（可直接粘贴的句子、与学生句子高度重合的长句） | 判为代写 → 修复调用 |
| 追问形式 | 诱导性、复合、祈使伪装问句 → 修复调用 |
| 句子框架 | 限制固定词数与槽位；与学生文本 4-gram 重合即删除 |
| 非英语输出 | 除非引用学生原文，否则判为违规 |

修复失败时**只删除违规条目**，保留其余可用反馈；空回复会重新生成，而**不会**被“修复”成凭空捏造的反馈。界面底部「诚信守门与运行记录」可展开查看本轮核对情况、模型、提示词版本与 token 数。

## 五、教师工具

「教师」页面全部在本机浏览器内运行：

- **任务设计器** — 议题与读者（可锁定）、结构要求、字数、关注的论证标准、本周语言重点、AI 使用规则、议题词汇表、最多 6 份材料包。导出 JSON 发给学生在第 1 步载入。
- **全班概览** — 导入学生导出的 JSON，查看追问回答数、修订决定分布、修订检查结果、全班的追问与学生发现，并导出汇总 CSV。校验码不一致会被标出。

课堂局域网部署：设置 `HOST`、`ALLOWED_HOSTS` 与 `ACCESS_CODE`；服务端有 FIFO 排队、每日调用与 token 上限。详见 `.env.example`。

## 六、数据与隐私

- 学习记录只保存在当前浏览器；支持导出、清空与**公用电脑模式**（关闭浏览器即清除）。
- 运行前需勾选**版本化的数据说明**（当前 `2026-10-v1`），同意记录会写入导出文件。
- 发送前自动检测邮箱、手机号、证件号与长数字，可一键遮蔽。
- 本工具**不使用 AI 文本检测器**；AI 使用说明由学生确认后写入记录。
- 导出记录带 SHA-256 校验码，可发现导出后的改动（但不能证明未被刻意篡改）。

```bash
npm test                 # 67 项自动化测试，全部离线，不消耗额度
```

最近一次真实评测（DeepSeek `deepseek-flash`，提示词版本 `38bd27ec863f`）：引用核实 100%，种子缺陷与注入预期 12/12 达成，立场评价性措辞 0 处。详见 [docs/评测报告.md](docs/评测报告.md)。

## 九、已知限制

- 单一提供方（DeepSeek）、单一模型；角色间一致**不等于**独立事实核验。
- 守门基于正则与词序匹配，不是语义理解：会漏掉改写得很彻底的代写，也可能误删个别合法表达（误删会记录在守门日志中）。
- 修订检查描述的是“文本中可见的变化”，不是论证质量评分。
- 尚未在真实课堂中验证学习成效；`docs/` 中的研究设计正是为此准备。
