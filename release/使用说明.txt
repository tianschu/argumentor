论证工坊 · ArguMentor v4.0 — 快速使用说明
（完整说明见 README.md；English: README.en.md；设计与评测见 docs/）

一、启动
需要 Node.js 20.3 或以上版本。
  macOS   ：双击“启动论证工坊.command”
  Windows ：双击“启动论证工坊.bat”
  任意系统：npm run setup 然后 npm start
浏览器打开 http://localhost:4186

首次配置时在终端输入 DeepSeek 模型名称与 API 密钥（输入时不显示）。
密钥保存在项目文件夹之外：
  macOS/Linux: ~/.config/argumentor/env
  Windows    : %APPDATA%\ArguMentor\env
因此复制或压缩本文件夹不会泄露密钥。

  npm run check          免费自检：验证密钥与模型，不消耗 token
  npm run start:offline  离线模板模式：不调用 DeepSeek，界面明确标注“非 AI 反馈”

二、学习流程（五步）
1 明确任务  议题、读者、主张、主张限定
2 构建论证  理由—证据—证据类型—来源—双层推理联系；异议与回应策略
            引用教师材料会被逐词核对
3 追问对话  先自评，再运行四角色反馈；回答苏格拉底式追问（每题最多三轮）
            看不懂的反馈可点“这条什么意思？”单独追问
4 自主修订  对每条修订重点作出决定（采纳／调整／不采纳／还没看懂）并写明理由
            学生亲自改写；可显示词级差异
5 检查反思  修订检查只描述“读者现在能看到什么”，不打分
            写下可迁移策略，确认 AI 使用说明，导出记录

三、写作要求
论证内容与 AI 反馈均使用英语；界面可中英切换。
英语正文中允许括号内的简短中文专名（如 Kunqu（昆曲））；
“来源”字段可直接填写中文文献题名。

四、学术诚信与数据
AI 只提问和指出问题，不代写；虚构文献、数据、链接与改写句由程序拦截。
本工具不使用 AI 文本检测器。
学习记录只保存在当前浏览器，可导出或清空；公用电脑模式下关闭浏览器即清除。
运行前需阅读并同意数据说明。请勿输入姓名、学号、联系方式等个人信息
（系统会在发送前自动检测并支持一键遮蔽）。

五、教师
“教师”页面可设计任务文件（含最多 6 份材料包）发给学生载入，
并可导入学生导出的记录查看全班概览、导出 CSV。
课堂局域网部署见 .env.example 与 README.md。
